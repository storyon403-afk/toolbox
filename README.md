<h1 align="center">Toolbox</h1>
<p align="center">A few small tools. Maybe one is useful to you.</p>
<p align="center">English · <a href="README.zh-CN.md">简体中文</a> · <a href="https://storyon403-afk.github.io/toolbox/?lang=en">Take a look ↗</a></p>

Review a document, sketch an interface, remember new words, or take useful content out of a video. Pick what you need.

## What can they do?

| Tool | When it helps |
| --- | --- |
| [RD · DocsBridge](tools/rd/README.md) | Getting feedback on a draft? Keep each comment beside the words it refers to. |
| [DesignDoc · Forma](tools/designdoc/design-canvas/README.md) | Have an app idea? Draw the screens and link them into a clickable prototype. |
| [LanguageMap](tools/languagemap/README.md) | Losing track of new words? Add your own definitions, connect related words, and revisit them by date. |
| [LinkParsing · LinkParse](tools/linkparsing/README.en.md) | Need something from a video? Extract speech, on-screen text, audio, or still frames. |

Each tool can be used independently. Toolbox brings them into one place.

## Try it

Download the unsigned Windows 11 x64 packages from [Releases](https://github.com/storyon403-afk/toolbox/releases/latest). Extract Toolbox and open `Toolbox.exe`, then check for updates to load the tool catalog. Each tool also has an independent ZIP. See the [installation guide](docs/INSTALL.md) for prerequisites and current limits.

To run Toolbox from source, use Node.js 22.12 or newer:

```sh
npm ci
npm run setup
npm start
```
