# Forma 2.1 · 本地设计工作台

面向个人界面设计与交互原型的轻量工具。沿用原有 Forma 风格，加入本地 Orbit / Figma 参考稿。无需账号、Figma 额度或付费 API，编辑器没有运行时网络请求。

## 打开

最简单的方式：用桌面浏览器打开上一级目录的 `Forma.html`，无需安装。`dist/index.html` 也是离线入口。

推荐固定地址使用，以保持浏览器保存位置一致：

```sh
cd /Users/storyon/Development/DesignDoc/design-canvas
npm start
```

打开 <http://127.0.0.1:5173>。启动服务只需 Node.js，**无需 npm install**。服务仅监听本机地址。

## 精简工作区

顶部左侧图标展开画板与图层，右侧图标展开属性面板；面板内部的箭头可收起。开关状态独立于设计文件保存。窗口宽度不超过 900px 时，面板默认收起并作为浮层打开，画布始终占满窗口。

底部聚焦图标适应当前画板；点击百分比可以选择 50% / 100% / 200% 或查看全部。双击画板标题聚焦；在总览的低倍率下，双击画板也会聚焦。加减按钮和 Ctrl/⌘ + 滚轮缩放继续可用。面板和工具条使用半透明背景及模糊；常用操作使用带中文提示与可访问名称的 SVG 图标组件。

## 设计 → 组件 → 原型 → 交付

- **画板**：桌面、移动、平板预设；复制、改名、拖动排列；F 查看全部，Shift+2 聚焦当前画板。
- **图层**：搜索、隐藏、锁定；文字、矩形、椭圆、图片；双击文字编辑，Escape 取消输入。
- **布局**：Shift 多选、框选、分组、四角缩放、六向对齐；横向/纵向顺排；拖动智能吸附，Alt 临时关闭吸附，Shift 限定方向/等比缩放。
- **样式**：尺寸、填充、圆角、描边、透明度、字号和字重；颜色变量联动所有绑定图层。
- **组件**：选中图层创建组件，左侧插入关联实例；点击「更新组件及全部实例」统一更新。Cmd/Ctrl 点击选择组内单层。
- **原型**：选中图层 → 右侧「原型」→ 选择目标画板 →「预览」。预览支持显示热点和返回。
- **交付**：JSON 完整设计文件、离线交互 HTML、当前画板 SVG / PNG；右侧「交付」提供 CSS 和变量。
- **命令搜索**：Cmd/Ctrl+K，按上下键选择，Enter 执行。

快捷键：V 选择、H 或空格平移、T 文字、R 矩形、O 椭圆、Cmd/Ctrl+D 复制、G 分组（加 Shift 解组）、Z 撤销（加 Shift 重做）、方向键移动（加 Shift 为 10px）、Cmd/Ctrl+S 导出 JSON。图层复制粘贴使用应用内部剪贴板。

左侧「打开 Orbit 设计示例」将加入三张可编辑画板，包含搜索 → 指令 → 外观设置 → 关闭返回的热点。它来自本地保存的 SVG 参考稿，渐变背景简化为纯色；没有访问 Figma 在线文件或消耗额度。

## 保存与 GPT 协作

自动保存使用当前浏览器的 localStorage。v1 文件可导入；旧版保存自动读取并迁移到 v2 新键，保留 v1 原始键。不同浏览器、地址和文件入口的存储相互独立。清理浏览器数据会删除本地设计，请定期导出 JSON。

导入会先验证结构、唯一 ID、几何、颜色和引用；失败不改动现有文档。成功导入可撤销。保存空间不足时显示提示，内存中的设计仍可导出。

导出的 JSON 可以交给 GPT/Codex 修改，再导回工作台。没有内置 AI 调用或 API 密钥设置。文件根结构：

```text
version: 2
 title: 项目名
 boards[]: id, name, x, y, w, h, bg, elements[]
 tokens[]: id, name, value
 components[]: id, name, elements[]
```

图层使用 `type`（text/rect/ellipse/image）、位置尺寸、`fill`、`fillToken`、`text`、`groupId`、`componentId`、`link` 等字段。完整字段与校验约束见 `src/core.js`。不支持远程图片 URL；图片嵌入为 PNG/JPEG/WebP/GIF data URL。

## 能力边界

这是个人设计工作台的可用基础版。暂不支持 `.fig` 文件、多人实时协作、贝塞尔钢笔、旋转、嵌套自动布局、组件变体和逐属性覆盖。分组和组件是单层集合；组件统一更新会覆盖各实例外观，保留位置。顺排是一次性操作，不会持续响应内容变化。

导出的 HTML 是固定画板原型，可自动缩放并保留点击跳转，不是生产级响应式页面。SVG / PNG 使用本机字体与测量换行，复杂排版可能与编辑器略有差异。PNG 最高 2×，大画板自动降低倍率以控制内存。默认示例里的开关等控件只有绘制外观，只有显式绑定的热点会执行跳转。手机浏览器仅提供紧凑视图，完整编辑建议桌面使用。

## 源码与验证

- `src/core.js`：文档校验、迁移、历史、几何、组件、SVG 序列化。
- `src/app.js`：画布事件、图层与检查器、命令面板、导入导出。
- `src/seed.js`：本地可编辑示例，`scripts/seed.py` 可从原始素材重新生成。
- `src/style.css`、`src/index.html`：视觉与界面。
- `src/ui.js`：统一的本地 SVG 图标组件。
- `scripts/build.cjs`：生成 dist 和单文件 Forma.html。
- `docs/DESIGN.md`：范围、交互与技术设计。

```sh
npm run build
npm test
# 浏览器测试仅是开发依赖，普通使用无需安装：
npm ci
npx playwright install chromium
npm run test:browser
npm run test:ui
```

可用 `FORMA_BROWSER_PATH` 指向已有 Chromium 可执行文件。浏览器测试需要先运行 `npm start`。测试在隔离浏览器环境中运行，不会清理或修改个人浏览器的设计数据。
