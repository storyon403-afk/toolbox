# Toolbox product page

A local showcase of the four tools, with Chinese, English and Japanese versions.

From the repository root, run `python3 -m http.server 8793 --bind 127.0.0.1`, then open `http://127.0.0.1:8793/website/`. Serve the repository root so usage/source links resolve. The HTML also opens directly from disk. Append `?lang=en`, `?lang=zh-CN` or `?lang=ja` to select a language. Without JavaScript, Chinese content and tool links remain available.

The mark and interface previews are original project assets. They are illustrative screenshots, not live tool sessions. Download builds from [GitHub Releases](https://github.com/storyon403-afk/toolbox/releases); see [installation](../docs/INSTALL.md) and [build instructions](../docs/BUILD.md).
